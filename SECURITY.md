# Security Policy

## Supported versions

Only the latest release gets fixes. Margin is an offline single player game with no network code, accounts or servers, so the attack surface is small, but we still want to hear about problems.

| Version | Supported |
|:--------|:---------:|
| 0.1.x   | yes       |
| < 0.1   | no        |

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private reporting instead: on the repository page go to Security, then Report a vulnerability. Include the version, your platform, steps to reproduce and what an attacker could do with it.

Useful reports include, for example, a crafted file in `data/` that crashes or misleads the game, or a release build that differs from the source.

We aim to reply within a week and will keep you posted until the fix ships. Tell us if you want to be credited in the changelog.
